# WordCraft: Thai Distributed and Thai line breaking test

Test documents and results for the open WordCraft pull requests
[#3072](https://github.com/storytold/wordcraft/pull/3072) (Thai Distributed alignment) and
[#2642](https://github.com/storytold/wordcraft/pull/2642) (dictionary line breaking for Thai/Lao).

> Prepared with the help of an AI coding agent (Claude Opus 5.5 via OpenCode).

- `docs/paragraphs.txt`: three paragraphs from the LibreOffice tdf#168666 test document and the
  `[A]` paragraph from WordCraft issue #1548.
- `docs/sarabun14-*.docx`: those paragraphs in Sarabun 14 pt, A4, 2 cm margins, generated by
  `gen_docx.py` with `w:jc` = `thaiDistribute`, `both` or `left`. The `-zwsp` variant has U+200B
  between Thai words, inserted by `Zwsp.java` (ICU4J 79.1 line `BreakIterator`).
- `thai-distributed-compare.png`: `wordcraft-cli convert` to PDF, page 1, right edge of the text
  area in blue.

```bash
java -cp icu4j-79.1.jar Zwsp.java docs/paragraphs.txt > paragraphs-zwsp.txt
python3 gen_docx.py docs/paragraphs.txt Sarabun 28 thaiDistribute out.docx
```
